КАРТА ЛПУ 2.0 — ОНОВЛЕНИЙ ПОШУК

Файли:
- index.html
- app.js
- styles.css
- data.json

Запуск:
1. Розпакуйте всі файли в одну папку.
2. Відкрийте папку через VS Code та запустіть index.html через Live Server.
3. Не відкривайте index.html напряму через file://.

Що змінено:
- Після вибору міста показуються всі клініки цього міста, навіть якщо спеціальність не задана.
- У режимі перегляду міста картки показують адреси та рівні клінік без тегів спеціальностей.
- Після введення спеціальності залишаються лише клініки, у яких є відповідна спеціальність.
- Фільтр району з'являється лише для Києва, Львова та Дніпра.
- При виборі міста карта My Maps отримує параметри центрування на відповідне місто.
- У картці є перехід до конкретної адреси клініки в Google Maps.

ВАЖЛИВІ ОБМЕЖЕННЯ ДАНИХ І КАРТИ:
- У вихідній базі поле district для адрес Києва, Львова та Дніпра не містить надійних адміністративних районів. Наявні значення часто є мікрорайонами або орієнтирами. Вони не були автоматично перейменовані на адміністративні райони.
- Тому список адміністративних районів у фільтрі вже передбачений, але для фактичної фільтрації треба заповнити location.district офіційним районом кожної адреси. Інакше вибір району не дасть коректних результатів.
- Вбудована Google My Maps працює в iframe на сторонньому домені. З міркувань безпеки браузера сайт не може примусово вибрати конкретну мітку або керувати її масштабом усередині карти. Тому конкретна адреса відкривається окремо в Google Maps; карта My Maps при виборі міста отримує спробу центрування через параметри ll/z.

База data.json містить 1 712 клінік після видалення клінік без адрес.
